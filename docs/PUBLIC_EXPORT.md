# 公开导出范围

本仓库使用全新 Git 历史，只导出人工选定的通用代码。未复制原项目 Git 对象、提交历史或本地配置。

## 已保留与处理

- Agent 基类、工具注册与调用、按注册顺序路由。
- 模型聊天、JSON 解析、超时与重试；删除专业教务意图提示词及其分类逻辑。
- 内存统计；删除读取原项目评测数据及固定准确率的逻辑。
- 将调度器中的教务部门指引改为通用学习指引。
- 显式禁用 SDK 内置重试，避免与客户端自定义重试叠加；模型调用日志不输出完整异常。
- 新增独立示例，三个课程及其先修关系均为虚构。

## 未导出

- 原学校名称、学校专用页面、培养方案、教学大纲与认证映射。
- 原课程、知识点、问题与能力图谱，以及图谱导出表格。
- 教学文件、评测集、评测报告、截图与演示资产。
- `.env`、真实 API 密钥、数据库凭据、管理员配置与认证代码。
- SQLite 数据库、FAISS 索引、日志、会话、模型缓存及个人开发配置。
- 原项目 README、交付文档与原 Git 历史。

配置示例只包含本地服务地址和本地模型使用的占位值。公开代码中未复制原项目配置文件的实际值。此范围说明描述当前导出，不保证后续自行添加的文件仍适合公开。
