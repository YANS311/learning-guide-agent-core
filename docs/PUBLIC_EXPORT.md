# 公开导出范围

本仓库使用全新 Git 历史，只导出人工选定的通用代码。未复制原项目 Git 对象、提交历史或本地配置。

## Java 与 Go 脱敏示例

新增的 `java/` 与 `go/` 根据本仓库已经脱敏的公开示例重新实现，提供相同的虚构课程、Agent/工具接口、按顺序路由、模型聊天、SSE 事件及内存统计。它们不是原学校系统的完整跨语言迁移，未读取原项目的 `.env`、文档、图谱、数据库或历史提交。

- Java 使用 JDK HttpServer 与 Jackson；Go 使用标准库 HTTP 与 JSON。
- 默认离线、绑定回环地址，默认端口分别为 8081、8082。
- 模型连接只使用用户自行设置的进程环境变量，不自动读取 `.env`。
- 示例只记录累计数量、路由、工具使用次数、延迟和失败数，不记录问题、回答或模型凭据。
- 测试仅使用虚构输入和本机模拟模型，不传输原项目资料或调用真实远程模型。
- JAR、class、可执行文件、覆盖率与 Maven `target/` 已加入忽略规则，公开提交只包含源代码、构建描述、测试和文档。

## 已保留与处理

- Agent 基类、工具注册与调用、按注册顺序路由。
- 模型聊天、JSON 解析、超时与重试；删除专业教务意图提示词及其分类逻辑。
- 内存统计；删除读取原项目评测数据及固定准确率的逻辑。
- 将调度器中的教务部门指引改为通用学习指引。
- 显式禁用 SDK 内置重试，避免与客户端自定义重试叠加；模型调用日志不输出完整异常。
- 新增独立示例，三个课程及其先修关系均为虚构。
